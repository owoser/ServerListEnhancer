# 加入游戏与最低版本要求

本文说明两端“加入游戏”按钮的行为、Windows 客户端的 LeviLamina 最低版本要求，以及从本模组发起的会话退出后的落点。

## Windows

### 行为

- 打开“服务器列表”后**不会默认选中**任何条目；未选中时，行列表与详情之间不显示按钮。
- 选中某一行后，行列表与详情之间出现原版绿色“加入游戏”按钮（复用游戏自带的按钮贴图与三态）。
- 点击按钮直接把当前选中条目的地址与端口交给游戏连接，不写入原版服务器列表，也不改动 `servers.json`。
- 翻页、重新打开列表、保存或删除条目都会清除选择，按钮随之隐藏；连接进行中按钮显示“正在连接…”，重复点击会被忽略。

### 连接实现

连接使用 LeviLamina 26.60.8 起提供的 `World::ServerWorldJoiner::joinExternalServer`（对应接口申请 [mcapi-requests#352](https://github.com/LiteLDev/mcapi-requests/issues/352)）。

该调用必须发生在客户端主线程的 `ClientInstance::$update` 之后：LeviLamina 的 `ClientThreadExecutor` 只在存在 `ClientLevel` 时消费任务，在主菜单提交会一直排队。因此模组把一个一次性请求挂到下一次更新上再调用。

调用前会先用 `SymbolView` 解析符号；解析失败说明当前进程使用的符号数据与 LL 版本不匹配，此时给出中文提示而不是直接崩溃。**只替换 `LeviLamina.dll` 而不更新配套的 `bedrock_runtime_data` 时，就是这个状态。**

### 退出后回首页

只有“由本模组的加入按钮发起、并且真的进入过世界”的会话才会被接管：

1. 进服时记录会话状态；
2. 退出世界时进入“等待菜单”状态；
3. 客户端更新回调在等级与玩家都已卸载、且没有待处理的界面调度时，检查屏幕栈；
4. 如果落点是世界列表（`play_screen` 或 OreUI 的 `ui://./hbui/index.html`）且下层存在 `start_screen`，就按名字弹掉世界列表这一层，回到首页。

从原版入口进入的会话不会记录状态，因此导航完全保持原版行为；退出确认框等原版流程也不受影响。

## Android

- 首页入口打开列表后，未选中时按钮为暗色且不可点击；选中后变亮绿并可点击。
- 点击后通过启动器的 `minecraft://connect/?serverUrl=<地址>&serverPort=<端口>` 深链交给游戏本身连接，因此仍会走原版的确认与资源包流程。
- 退出沿用游戏自身的流程，**这一端不做自动返回首页**：Android 上判断“已停在世界列表”只能依赖画面特征，玩家自定义资源包/主题会改掉这些特征，误判后强行注入返回键的风险高于收益，因此保留原版行为（退出后由玩家自己按一次返回）。

## Windows 最低版本

- 客户端要求 **LeviLamina 26.60.8 及以上**，且必须使用与之匹配的符号数据。
- 构建侧：`xmake` 的 `ll_version` 默认 26.60.8，客户端在 `on_load` 阶段拒绝更旧的 SDK。
- 运行侧：模组在 `load()` 最前面用真实的 `ll::getLoaderVersion()` 与 `ll::data::VersionRequirement` 比较，低于 26.60.8 直接拒绝加载并写日志。
- 为什么不用清单依赖表达：LeviLamina 自身是 `preload-native`，不会进入普通 native 模组的依赖集合；在 `manifest.json` 里写 `{"name":"LeviLamina"}` 会被加载器判为缺少依赖而拒绝加载整个模组。因此客户端清单只在 `extraInfo` 中记录说明性的最低版本，真正的门禁是运行时的版本检查。
- 服务端不受该限制影响，可单独指定版本构建。

## 验收要点

| 项目 | Windows | Android |
| --- | --- | --- |
| 未选中不显示/不可点 | 列表打开、翻页、保存后均无按钮 | 暗色按钮，点击无效 |
| 选中后可加入 | 绿色按钮出现在行列表与详情之间 | 亮绿按钮，可点击 |
| 实际连接 | 进入目标服务器世界 | 经原版确认后进入世界 |
| 退出落点 | 本模组发起的会话回到首页 | 沿用游戏自身流程（不自动导航） |
| 用户数据 | `servers.json`、配置、缓存原样保留 | 同左 |

> 版本门禁只保证“低于 26.60.8 会被拒绝”，不代表未来游戏版本或其它模组组合已经验证。
