## 边界和未实现项

- 显示“UDP未响应”不等同于离线；NetherNet需明确启用独立udpProbePort后才能测专用回显。测试19135在收尾时关闭，未擅自保留监听。
- 64MiB为自有GIF解码像素预算；32MiB为自有动画纹理像素量预算。10次CPU零计数不是整个Minecraft进程的内存泄漏证明，游戏静态纹理缓存/驱动额外显存不在这两个计数中。
- 暂无完整IME组合输入、WebP/SVG和原版API点击直连；点击行是选中详情，不是连接成功。详见[MCAPI申请](<mcapi-request.md>)。
- 验证过程中未替换用户的LeviLamina；代码发布状态以Git提交历史为准。
